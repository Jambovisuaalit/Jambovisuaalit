## Palautus

**Vercelin kautta nopeimmin:** avaa projektin deployment `dpl_Hv9WcJc5ttS96ZfRky2cHWDNVFpx` ja valitse Redeploy → Production. Varmista projektitunnus ja ajantasaiset domain-asetukset ennen hyväksyntää.

**Varmuuskopiosta:** lataa tämä GitHub-haara ZIP-pakettina, pura ja käytä kansion `site/` sisältöä Vercel-projektin julkaisulähteenä. Staattisen sivuston pääsivu on `site/index.html`. Vercel-projektin julkaisukansioksi valitaan `site/`, ei tämän varmuuskopiohaaran juurta.

Tiedostojen Git SHA-1 -tunnisteet löytyvät tiedostosta `FILE_MANIFEST.json`.

Huom: sivusto ohjaa käyttäjät Airbnbhen/Bookingiin, ei omaa varausjärjestelmää. Kolmannen osapuolen saatavuutta ei tarkistettu.
